The first release of Tiphys: an agent that runs as a service on an Ubuntu server and is reached from a terminal app.

## Install

On an Ubuntu server (x86_64 or arm64), as a user who can use `sudo`:

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/tiphys/main/install.sh | sh
```

Log out and in again, run `tiphys`, and add a connection in the app.

## What is in it

- **A terminal app.** Set up a connection to any endpoint that speaks Chat Completions, pick a model, and talk. The key is typed into a masked field and never passed on a command line. A model is checked with a real tool call before it is saved.
- **Tools.** Reading, searching, writing and editing files, and running commands.
- **Approvals.** Looking around and changes inside the agent's own home run at once. `sudo`, packages and services, writing outside its home, files that usually hold a secret, and programs whose effects cannot be read off the command line ask first. A short list of things is refused whoever asks.
- **An action log.** Every tool call is one entry in a hash-chained file. `tiphys log` lists it and `tiphys log verify` checks it.
- **A daemon.** Lose the connection in the middle of a turn and the turn carries on; open the app again and the conversation is there.
- **Two users.** The daemon holds the keys and the state as one user. Everything the agent does is done as a second user who cannot read them.
- **A daily spending limit**, $5.00 unless you set another.

## Known limits

- One wire format, Chat Completions. One model connection is used at a time.
- No chat, scheduled jobs, memory or web tools yet.
- The rules about commands have met their own tests and little real use. Expect some commands to ask when they need not. `for` loops and anything with a variable always ask.
- The conversation is drawn as plain text, and a long diff in an approval card cannot be scrolled.
- A call whose price is not known is not counted toward the spending limit.
- The release is checked against its SHA-256 checksums, which come from the same place as the release. It is not signed.
