Tiphys can be talked to from a Telegram chat, and a long conversation no longer outgrows its model.

## Update

Run the installer again. Your data is not touched, and the service is restarted.

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/tiphys/main/install.sh | sh
```

## New

- **Telegram.** Type `/telegram` in the app to set up a chat bot.
  - Ask @BotFather in Telegram for a bot and paste its token into the masked field. The token is checked with Telegram, then stored like a key. No command takes it.
  - Press `p` to pair. The app shows a six-digit code; send it to the bot from your own Telegram account, and the app shows who it came from and asks whether that was you. Only `y` is a yes.
  - The bot answers paired users in a private chat, and nobody else. Anyone not paired gets no reply of any kind, and groups are ignored.
  - Each chat is a conversation of its own. `/new` starts a fresh one and `/stop` stops what is running. A message sent while a turn runs waits its turn.
  - What has to ask arrives with Approve and Deny buttons. A question nobody answers in 300 seconds is a no.
  - The server opens no port: the daemon asks Telegram for new messages.
  - What you sent while Tiphys was not running is not acted on when it starts. The chat is told, and you can send it again.
- **Long conversations are cut down to fit the model.** When a conversation nears three quarters of the model's context window, its oldest part is left out of what the model is sent: old tool results first, then whole turns. Nothing is deleted from the session, and you are told when it happens. No model is asked to summarise anything.
- `tiphys doctor` says whether a bot is set up and how many users it answers.

## Changed

- The app and the daemon speak a new version of their protocol. Both come from the one binary, and the update restarts the service, so there is nothing to do; an app left open across the update has to be opened again.

## Known limits

- Telegram has been tested against a stand-in for its Bot API and not yet against Telegram itself.
- Text only, and plain: a photo or a file gets "Tiphys reads text only for now", and a model that writes Markdown shows its asterisks.
- A user is taken off the allowlist by editing `[telegram] allow` in `settings.toml`; the app adds and does not remove.
- What compaction leaves out is gone from the model's view. There is no memory yet to carry a fact past it.
