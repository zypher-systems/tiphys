The owner of an installed Tiphys can read the files the agent writes.

## Update

Run the installer again. Your data is not touched.

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/tiphys/main/install.sh | sh
```

Log out and in again afterwards, so that the new group takes effect.

## Fixed

- **The owner could not read the agent's home.** The install put the owner in the daemon's group, which opens the socket, and not in the agent's group, which owns `/home/tiphys`. A file the agent was asked to write could not be read back without `sudo`. The install now adds the owner to both groups. The agent's home is open to its group for reading only, so you can read the agent's files and cannot change them.
- The message after an install names both groups, `tiphysd` and `tiphys`, and says what each is for.
